🧠 MindVault+

About the Game

MindVault+ is a memory-based brain training game designed to improve focus, attention, and short-term memory. Each level challenges you with longer number sequences.

How to Play

  1. Click Start to begin
  2. A number appears briefly
  3. Memorize the number
  4. Type it correctly to level up
  5. Each level increases difficulty
